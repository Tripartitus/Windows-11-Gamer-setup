## ✨ What It Does

This script transforms a fresh or bloated Windows 11 installation into a **high-performance gaming machine** with a single click.

### Key Features

- **System Repair** — Full DISM + SFC + disk health check
- **Deep Cleanup** — Removes all temp files, prefetch, cache, and Recycle Bin
- **Driver & Hardware Check** — Shows GPU, network, and any problematic devices
- **Gaming Optimizations**
  - Ultimate Performance power plan
  - Hardware-accelerated GPU Scheduling
  - Visual effects set to "Best Performance"
- **Low Latency Network**
  - DNS + Winsock + IP stack reset
  - **Nagle’s Algorithm disabled** on all active adapters (reduces ping & input lag)
- **Aggressive Debloat**
  - Removes 20+ bloatware apps (Bing, Cortana, Solitaire, etc.)
  - Completely removes OneDrive
  - Disables telemetry services and scheduled tasks
- **Privacy Hardening**
  - Disables Recall, Copilot AI features, activity tracking, and fingerprinting vectors
  - Extensive registry tweaks for maximum privacy
- **Automatic Software Installation**
  - Visual C++ Redistributables (x64 + x86)
  - .NET Desktop Runtime 8
  - **Mozilla Firefox**
  - **WinRAR**
- **Fully Automated** — No prompts, no decisions, just run it and walk away
- **Detailed Logging** — Everything is logged to `C:\GamerSetup_*.log`
